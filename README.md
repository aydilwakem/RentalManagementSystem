# 🏡 Rental Management System

A comprehensive booking and management solution built for Canopy Farm PH to streamline rental operations. This system replaces manual tracking with a centralized, automated dashboard powered by the TALL stack.

### ✨ Technologies

- `Laravel`
- `Livewire`
- `Tailwind CSS`
- `AlpineJS`
- `MySQL`

### 🚀 Features

- **Centralized Admin Dashboard:** provides an intuitive management experience.
- **Real-time Booking Calendar:** visualizes availability and prevents overlapping reservations.
- **Automated Calculations:** handles booking fees, duration, and total costs instantly.
- **Reservation Status Tracking:** easy monitoring of pending, confirmed, and completed bookings.
- **Responsive Design:** optimized for desktop administration with mobile-friendly views.

### 📍 The Process

For Canopy Farm PH, relying on spreadsheets and direct messages to manage bookings wasn't just tedious, it was becoming unscalable. Our goal was to replace that manual chaos with a system that felt reliable and professional.

We decided to build on the TALL stack to maintain full control over the admin interface while keeping the application performance snappy. Ensuring that the calendar logic could accurately handle real-time availability and prevent overlapping dates required rigorous testing and complex validation rules. It took some late nights of debugging but seeing the system actually organize and fully automate the workflow has been incredibly satisfying. It's a huge step up from manual logs!

### 🚦 Running the Project

1. Clone the repository
2. Install PHP dependencies: `composer install`
3. Install NPM dependencies: `npm install` && `npm run build`
4. Set up your `.env` file and database
5. Run migrations: `php artisan migrate`
6. Run the development server: `php artisan serve`
